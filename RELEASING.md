# Releasing Skills Lab

Collection version: 1.0.1. The collection uses the [MIT License](LICENSE). Version, individual skill source identities, archive identity and installed state are separate; a version label does not establish publication or runtime support.

1. Bind the exact repository/account, current source revisions, complete public selection, notices and intended audience. Preserve the selected-export source relationship. A later identity or licence change requires its own affected review and exact decision; do not repeat an unchanged decision for routine preparation.
2. Freeze all final raw files after generation. [inventory.json](inventory.json) covers every other public file, explicitly excluding itself. Hash that inventory and the final single-root archive externally. Retain issued bytes and source relationships; rebuilding is not automatically the same artifact.
3. Check complete resources, formats, local links, licence notices and intended public exposure. Use affected checks where unchanged-byte evidence supports reuse. Disclose untested hosts and evidence recipients cannot reproduce; do not install or execute the skills merely to inspect their files.
4. Obtain the owner's exact decision for the validated payload and included effects. One dependency-ordered envelope can cover empty repository creation, pre-seed controls, clean initial source publication, protection and readback. Subsequent source changes use the actual protected PR workflow. The first empty-repository seed is a specific bootstrap exception, not continuing direct-write permission.
5. Recheck current target identity, usable permissions, defaults, triggers and required controls immediately before effects. Publish only the approved selection. No tag, release asset, announcement, Pages site, hosted job, private-source transfer or install is implicit.
6. Verify actual stored files, full paths/modes, resulting revision, visibility, controls and relevant recipient-visible surfaces. Preserve partial/unknown outcomes; inspect actual state before an authorized retry. Do not overwrite, force, delete or silently roll back for convenience.

The [rights record](RIGHTS.md) and complete LICENSE accompany the skill folders and documentation. Keep the copyright and permission notice in copies or substantial portions as the licence requires. A future component with additional notices must retain them through packaging; never silently replace incompatible terms with this collection's licence.
